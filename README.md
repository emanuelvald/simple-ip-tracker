# simple-ip-tracker
A lightweight WordPress plugin to track visitor IP addresses and detect fraudulent clicks on PPC advertising campaigns (Google Ads, Meta Ads). Identify competitors or bots repeatedly clicking your ads to waste your budget

## Features

- Track all visitor IPs automatically
- Detect suspicious IPs (multiple visits in 24h)
- View statistics: total visits, unique IPs, today's traffic
- UTM parameter tracking (source, medium, campaign)
- Export data to CSV
- Real-time fraud detection alerts

## Use Case

Perfect for agencies and businesses running PPC campaigns who want to:
- Identify competitors wasting your ad budget
- Detect bot traffic clicking your ads
- Monitor unusual visitor patterns
- Protect your advertising investment

## Installation

1. Upload to `/wp-content/plugins/simple-ip-tracker/`
2. Activate the plugin
3. Access via WordPress admin menu: IP Tracker

## Requirements

- WordPress 5.0 or higher
- PHP 7.2 or higher
- MySQL 5.6 or higher
